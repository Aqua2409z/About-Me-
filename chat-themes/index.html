Chat themes demo

make my chat feel alive ✨

Xong! Phía sau đoạn chat bây giờ là hình nền pixel chuyển động.

  • Gõ /theme vào ô chat để mở bảng chọn, dùng ← → để xem thử, Enter để áp dụng, Esc để đóng.
  • Gõ thẳng tên theme: /theme koi, /theme moon, /theme jelly…
  • Trên điện thoại: chạm vào nút ô vuông nhiều màu ở cạnh phải màn hình.

Có 8 theme: Claude Code, Cloud Drift, Honu Lagoon, Koi Pond, Jellyfish, Paper Boats, Fireflies, Moonlit.

làm sao để có cái này trên claude.ai?

Cài file userscript bên dưới. Nó chạy trên claude.ai trong trình duyệt (app Claude chính thức không cho cài thêm gì).

💻 Laptop: Chrome, Edge, Brave, Firefox

  1. Cài tiện ích Tampermonkey (Chrome: vào chrome://extensions, mở Chi tiết của Tampermonkey và bật Allow User Scripts).
  2. Bấm nút Cài userscript bên dưới, rồi bấm Install.
  3. Mở claude.ai và gõ /theme.

📱 iPhone / iPad: Safari

  1. Cài app miễn phí Userscripts từ App Store.
  2. Cài đặt → Safari → Tiện ích mở rộng → bật Userscripts, cho phép trên claude.ai.
  3. Mở nút Cài userscript trong Safari, chạm biểu tượng tiện ích trên thanh địa chỉ, chọn Userscripts → Install.

🤖 Android: Firefox

  1. Trong Firefox, vào Tiện ích (Add-ons) và cài Violentmonkey hoặc Tampermonkey.
  2. Mở nút Cài userscript rồi bấm Install. Vào claude.ai bằng Firefox.
⬇ Cài userscript Hướng dẫn chi tiết

nó hoạt động thế nào?

Một <canvas> toàn màn hình nằm sau trang, vẽ cảnh bằng lưới ô vuông nhỏ, mỗi ô là một ký tự ASCII. Script tìm các nền đặc của trang: nền lớn thì làm trong suốt, khung nhỏ (thanh bên, ô chat, bong bóng tin nhắn) thì thành kính mờ.

// mỗi theme chỉ là một object
{
  id: 'koi', name: 'Koi Pond', dark: true,
  bg(ctx, w, h) { /* gradient nền */ },
  init(world) { /* tạo cá, lá sen */ },
  frame(world, dt) { /* vẽ một khung hình */ },
}

Thử gõ gì đó vào ô chat bên dưới nhé.
